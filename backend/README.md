# Momentum backend

A planned Go backend with PostgreSQL on Neon that replaces Taskwarrior as Momentum's source of truth. Nothing is built yet; until it is, the terminal and macOS apps keep using Taskwarrior.

See [ADR 0002](../docs/adr/0002-go-postgres-backend.md) for the decision and the [implementation plan](../docs/plans/backend.md) for the work.
